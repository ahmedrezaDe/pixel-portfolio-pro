# Parallel Realm: my portfolio

A game-styled personal portfolio: drift through a galaxy, open a "rift" to explore each project, and use the built-in terminal (`help`, `skills`, `run-thermal`, `run-telemetry`).

**Live:** https://erza-os.vercel.app

## What's inside

- Projects: [thermal-ai-lab](https://github.com/ahmedrezaDe/thermal-ai-lab), [nexus-metric-core](https://github.com/ahmedrezaDe/nexus-metric-core), [odyssey](https://github.com/ahmedrezaDe/odyssey) and work in progress
- All content lives in one file, [`src/lib/portfolioConfig.ts`](src/lib/portfolioConfig.ts); the components only render it
- Each project's architecture diagram is drawn from that config

## Stack

React 19 · TanStack Start · Vite · Tailwind CSS · Motion · deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

## How it was built

Designed by me (Ahmed Reza). The first scaffold came from Lovable; I directed the design and content, and much of the code was written with AI coding assistants, then reviewed and tested by me.
